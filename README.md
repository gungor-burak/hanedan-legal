# hanedan-legal

Legal documents for **Hanedan: Osmanlı** (iOS App Store).

Hosted at: https://gungor-burak.github.io/hanedan-legal/

## Files

- `index.html` — landing page with links to all four documents
- `privacy-en.html` / `privacy-tr.html` — Privacy Policy (EN + TR)
- `terms-en.html` / `terms-tr.html` — Terms of Use (EN + TR)

## URLs (for App Store Connect)

After enabling GitHub Pages on this repo (Settings → Pages → Source: `main` branch, `/` root):

- Privacy (EN): `https://gungor-burak.github.io/hanedan-legal/privacy-en.html`
- Privacy (TR): `https://gungor-burak.github.io/hanedan-legal/privacy-tr.html`
- Terms (EN): `https://gungor-burak.github.io/hanedan-legal/terms-en.html`
- Terms (TR): `https://gungor-burak.github.io/hanedan-legal/terms-tr.html`

## Updating

Edit the HTML files, bump the "Effective date" at the top, commit, push. Pages updates within ~1 minute.
